ELION — postavljanje na GitHub Pages

Postavite index.html i foldere css, js, assets u koren repozitorijuma.
Prikaz uređaja koristi fotografije i prelaz, nije interaktivni 3D model.
Proces koristi šest ilustrativnih kadrova.
Kontakt otvara program za e-poštu, bez servera i bez lažne potvrde slanja.
Pre objave potvrditi postojeći telefon i prodaja@elio.rs, vreme primene, napajanje i kapacitet rolne. Dimenzije i materijali nisu predstavljeni kao potvrđeni.
